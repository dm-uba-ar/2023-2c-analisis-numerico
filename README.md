  # Otros

  - **Inscripción**. Para poder ser incluido en las Actas de Trabajos
    Prácticos, en caso de aprobar los trabajos prácticos, **es necesario
    haberse inscripto** en la materia y haber completado la encuesta de
    evaluación docente.\
  - De acuerdo al
    Régimen de Correlatividades para las materias dictadas por el
    Departamento de Matemática,  para poder cursar  Análisis
    Numérico, **es necesario tener aprobados**  los 
    Trabajos Prácticos de Elementos de Cálculo Numérico, Medida y
    Probabilidad y Análisis Complejo; **así como** el Final de
    Probabilidades y Estadística.
  - **Régimen de aprobación de los Trabajos Prácticos**. Para firmar
    los trabajos prácticos se deberá aprobar dos parciales, y presentar dos
    trabajos computacionales. Habrá un recuperatorio para cada
    parcial.\
  - Información sobre la Secretaría de Promoción de la Equidad y Géneros de
    la Facultad y la Subcomisión de Género del DM.\
  - **Normas de seguridad**. Se recuerda que es **obligatoria** la
    lectura de las [normas de higiene y
    seguridad](http://www.dm.uba.ar/varios/normseg.html).
